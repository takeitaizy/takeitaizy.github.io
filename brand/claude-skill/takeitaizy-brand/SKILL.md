# Take It AIZY brand

Every deliverable that goes out under the Take It AIZY name carries the official
logo from `assets/`. Never redraw, trace, retype or recolor it. Always copy the
file.

## Pick the file

| Situation | File |
|---|---|
| Light background (default) | `assets/take-it-aizy-logo-navy.png` (docs) / `.svg` (web) |
| Navy, dark or photo background | `assets/take-it-aizy-logo-white.png` / `.svg` |
| Icon, avatar, small square, footer mark | `assets/take-it-aizy-icon.png` / `.svg` |
| The Z hourglass alone, no background | `assets/take-it-aizy-mark-navy.svg` / `-white.svg` |
| Website favicon set | `assets/favicon/` (svg, ico, 16, 32, 180, 192, 512) |

Use PNG in Word, Google Docs, Slides, Gamma and PDF. Use SVG on the web.

## Where it goes in a document or proposal

1. **Cover:** navy wordmark at the top, about 35-45% of the page width, with clear space around it.
2. **Header on every page after the cover:** small navy wordmark (about 30 mm wide) at the start edge (right side in Hebrew documents, left in English).
3. **Footer:** icon (about 8 mm) + `takeitaizy.dev` + `hello@takeitaizy.dev`.
4. **Decks:** white wordmark on a navy `#0E1C30` cover and closing slide; small navy icon in a corner of content slides.

In Hebrew documents the wordmark stays in Latin letters.

## Rules

- Colors: navy `#0E1C30` and white only for the logo. Body headings may use navy.
- In running text write "Take It AIZY". Use `takeitaizy` only for the domain and handles.
- Never stretch, rotate, crop, outline, add shadow or put the logo straight on a busy photo.
- Clear space: at least the height of the "TAKE IT" line on every side.
- Minimum size: wordmark 120 px / 30 mm wide; icon 16 px.
- Accent `#E8A33D` (sand) and the fonts Heebo + Montserrat are proposed, not approved. Use them only when asked to match the website.

## Before you hand over the deliverable

- [ ] Logo comes from `assets/`, untouched
- [ ] Right variant for the background (navy on light, white on dark)
- [ ] Cover, header and footer placement as above
- [ ] Name written "Take It AIZY" in the text
